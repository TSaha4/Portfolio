## 🛠️ About this site

The portfolio is built as one "forward pass" through a network: particles learn my name in the hero, projects live in a page-turning case-file book, and a pixel mini-me walks A* routes to my contact links.

- **Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS 4, Framer Motion
- **Content:** every fact lives in typed files under [`content/`](content/), so updates never touch layout code
- **Hosting:** Vercel

Run it locally:

```bash
npm install
npm run dev
```
